# Підтвердження зустрічі

1. Створи безкоштовний проєкт у Supabase.
2. Виконай `database/setup.sql` через SQL Editor.
3. У Vercel → Project Settings → Environment Variables додай:
   - `SUPABASE_URL` — Project URL із Supabase.
   - `SUPABASE_SERVICE_ROLE_KEY` — секретний ключ service_role із Supabase (НЕ anon key).
   - `ADMIN_VIEW_TOKEN` — довгий випадковий пароль для перегляду відповідей.
4. Зроби Redeploy у Vercel.
5. Після підтвердження часу дані зберігаються в таблиці `meeting_rsvps`.
6. Відкрий `/admin`, введи `ADMIN_VIEW_TOKEN` і переглянь відповіді.

Секрети не додавай у GitHub. Якщо не налаштувати базу, кнопка підтвердження покаже помилку та не створить фальшивого підтвердження.
Зверни увагу: форма публічна, тому за потреби перевіряй останній запис і час надходження. Для суворого захисту від сторонніх підтверджень потрібен окремий одноразовий токен запрошення.
